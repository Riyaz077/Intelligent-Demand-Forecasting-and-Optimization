# Data Dictionary

| Field | Description |
|---|---|
| date | Daily observation date |
| store_id | Synthetic store identifier |
| product_id | Synthetic product identifier |
| category | Product category |
| price | Simulated selling price |
| promotion | Promotion indicator (0/1) |
| temperature | Simulated temperature driver |
| holiday | Synthetic holiday/event indicator |
| demand | Simulated daily unit demand |
